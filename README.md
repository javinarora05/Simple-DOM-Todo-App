# ✅ Simple DOM Todo App

> A minimal vanilla-JavaScript Todo app with persistent browser storage.

## ✨ Features
- Add and delete tasks
- Prevent empty and duplicate entries
- Dynamic DOM rendering
- Persistent `localStorage`
- Fully client-side
